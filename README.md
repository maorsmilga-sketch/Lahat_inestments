# Lahat-CRM – GitHub Pages

Upload the files in this folder to the repository root on the `main` branch. Enable GitHub Pages at Settings > Pages > Deploy from a branch > main / (root).

The current app is the supplied V11 HTML. It uses browser localStorage. Google OAuth and Drive/Sheets syncing are **not yet implemented**. Do not enter sensitive real customer data into a public test deployment before validating privacy/security and backups.
